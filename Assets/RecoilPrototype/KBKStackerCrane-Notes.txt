KBK Stacker Crane gameplay device

Reference: user IMG_3477.HEIC sketch; Demag KBK stacker cranes:
https://www.demagcranes.com/en/products/cranes-and-cranes-sets/kbk-light-crane-system/kbk-stacker-cranes
KBK double-girder suspension rail, trolley, guided mast and lifting forks. Official systems commonly use manual crane/trolley travel and powered lifting; this gameplay version uses an automatic switch-driven sequence.

Warehouse hierarchy: Demag KBK Stacker Crane - editable
01 Start - floor level: right side, x22.5
02 Drop point - floor level: leftmost rack, x5
03 Travelling trolley and mast
04 Lift carriage and fork platform: SoftRoofPlatform, flush with floor when lowered
05 Fixed ground control - E: x9.6 in front of the second rack, on a floor pedestal; does not travel with the carriage: KBKCraneSwitch (instant interaction)
06 Scattered freight at drop point

KBKStackerCrane is on the device root. Adjustable lift height (3.4m), lift time (2s), travel time (5s), lowering time (2s), and return enabled. Start/destination are child markers that can be moved in Scene view.
E on the fixed floor switch: raise -> travel -> lower. Busy presses do not restart the sequence. E at the destination returns to the start using the same order. Reset/retry returns the device to the start.
The deck supports a player standing on its top, carries that player using the existing controller's collision handling, allows upward passage and water shots, and supports S+Jump drop-through. Flying/climbing/jumping riders are not forcibly attached.
Moving animation is procedural, with smooth acceleration/deceleration. No Rigidbody rewrite or Animator is required.
