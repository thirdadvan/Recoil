The scene is a separate copy of the saved factory interior. Enemies are inactive and doors cannot change scenes, so the effect can be inspected safely. The original factory and broadcast gameplay are unchanged. Reference lights help show distortion in the dark scene and can be disabled with H. This scene is intentionally not added to the normal game progression or build scene list.

Main Camera > BroadcastRefractionEffect:
Strength = world-space displacement (default 0.28m).
Packet Width = soft band width (4m).
Wavelength = spacing of bending crests (1.1m).
Irregularity = low-frequency unevenness (0.25).
Chromatic Aberration = subtle separation (0.045; set 0 for fewer texture samples).
Emitter = optional world-space source. If empty, a source is positioned beyond the left edge when each pulse is emitted. Source stays fixed in world space afterwards, including while the camera moves. Expanding moves rightward across the view; contracting moves leftward.

Implementation:
BroadcastRefraction.shader displaces samples of the camera's existing colour image. The smooth radial wave packet bends scenery and lighting, instead of painting a ring. At most four packets are combined in a single fullscreen pass; no GrabPass, new capture camera, per-frame textures, or CPU ring vertices are needed in shader mode. Inactive frames use a direct copy. Screen-edge displacement fades to prevent border streaking. OnGUI/HUD is drawn afterwards and remains readable.
BroadcastRefractionEffect observes SoundWaveManager's warning phase and command index. It never decides monster reactions. The only manager addition is drawBroadcastCircles, default true; test scene overrides it to false. Toggling old circles on can recreate visuals for already-active waves. The effect supports orthographic and perspective cameras in the Built-in renderer. Perspective uses a camera-plane metric at Perspective Reference Distance (18m in the 3D test), with a world-space source projected each frame; this is screen refraction, not a depth-resolved volumetric simulation. URP would need a different render hook.
